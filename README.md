# EcoRide - ECF Studi

Ce dépôt contient le projet de plateforme de covoiturage écoresponsable développé dans le cadre du TP DWWM (Studi).

## Objectif
Concevoir une application web permettant la mise en relation entre chauffeurs et passagers autour d’un système de crédits, avec des critères écologiques.
